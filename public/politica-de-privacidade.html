Política de Privacidade — Orienta+

Última atualização: 17/10/2025 · Versão 1.0
Seus dados são importantes. Esta política explica como coletamos, usamos e protegemos suas informações.
Índice 1. Escopo 2. Quais dados coletamos 3. Uso dos dados 4. Compartilhamento 5. Direitos dos titulares 6. Segurança 7. Retenção 8. Contato

1. Escopo

Esta Política de Privacidade descreve as práticas do Orienta+ relativas à coleta, uso, armazenamento e proteção de dados pessoais dos usuários da nossa plataforma web e mobile.

2. Quais dados coletamos

Podemos coletar:

  • Dados de identificação: nome, email, cpf/identificador quando aplicável.
  • Dados de perfil: foto, biografia, links para redes sociais.
  • Dados de uso: logs, atividade na plataforma, preferências.

3. Para que usamos os dados

Utilizamos os dados para:

  • Permitir o funcionamento do serviço — autenticação, perfis e agendamento de aulas.
  • Melhorar a experiência do usuário e produtos.
  • Enviar comunicações operacionais e, quando autorizado.
  • Cumprir obrigações legais e políticas internas.

4. Como e com quem compartilhamos

Não vendemos seus dados. Compartilhamos somente com:

  • Autoridades quando exigido por lei.

5. Direitos dos titulares

Você tem direitos sobre seus dados, incluindo:

  • Acesso, correção e exclusão de dados.
  • Portabilidade e revogação de consentimento.
  • Oposição ao processamento quando aplicável.

Para exercer seus direitos, entre em contato pelo e-mail: orientamais.app@gmail.com.br.

6. Segurança

Adotamos medidas técnicas e organizacionais para proteger os dados (ex.: criptografia em trânsito e em repouso, controles de acesso).

7. Retenção dos dados

Reteremos seus dados pelo tempo necessário para cumprir as finalidades descritas ou conforme exigido pela legislação aplicável.

8. Contato

Se tiver dúvidas sobre esta política, envie mensagem para: orientamais.app@gmail.com.br.
