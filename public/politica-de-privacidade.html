Política de Privacidade

Esta Política de Privacidade descreve como a plataforma OrientaMais coleta, usa, armazena e compartilha os dados pessoais dos usuários (mentores e mentorados). Nosso foco é oferecer um ambiente seguro para encontros educacionais online, com mínima coleta de dados e respeito à privacidade.

1. Dados que coletamos

Coletamos somente:

  • Nome e sobrenome — usados para identificação e para emissão de certificados.
  • E-mail — usado para autenticação, envio de convites/links de reunião e comunicações operacionais.
  • Localização (cidade, estado), nacionalidade — usados em estatísticas e relatórios agregados.
  • Data de nascimento — usada para validação de idade mínima (mentor ≥ 18, mentorado ≥ 16) e conformidade.
  • Descrição pessoal e link para rede social (ex.: LinkedIn) — informações de perfil e apresentação pública.
  • Dados técnicos de sessão (p.ex. JWT/session token) e informações de sessão necessárias para autenticação e operação da aplicação.

O que NÃO coletamos: CPF (não utilizamos CPF), fotos de perfil (não armazenamos imagens pessoais), mensagens de chat (não há chat interno), nem dados sensíveis.

2. Para que usamos os dados

  • Autenticação e controle de acesso à plataforma (JWT + sessão).
  • Envio de e-mails operacionais e convites (integração com API do Gmail).
  • Criação, publicação e gerenciamento de aulas (título, descrição, horários, links de apoio).
  • Geração de certificados: ao concluir/validar aulas, o sistema utiliza nome e sobrenome para gerar certificados.
  • Estatísticas agregadas de uso (por cidade/estado, número de aulas, presença) para fins administrativos e melhoria do serviço.
  • Verificação de idade mínima para cadastro e atribuição de papéis (mentor/mentorado).

3. Segurança e armazenamento

Adotamos medidas técnicas e organizacionais para proteger os dados:

  • Senhas: são hashadas com bcrypt.
  • Transporte: comunicação via HTTPS.
  • Sessões: utilizamos JWT para gerenciamento de sessão; a aplicação também usa cookie de sessão (KUKS para sessão — se aplicável) apenas para controle de autenticação técnica.
  • Logs: registramos ID do usuário, horário e ação; não armazenamos IP nem conteúdo de mensagens.
  • Armazenamento: atualmente os dados estão em servidor local com banco Postgres; há plano futuro de migração para cloud.
  • Envio de e-mail: integrado via API do Gmail (conta da plataforma).
  • Controle de acesso: validações no front-end e back-end para isolar telas e recursos entre papéis (mentor, mentorado, admin).

Apesar das medidas, ressaltamos que não monitoramos ou gravamos reuniões realizadas em serviços de terceiros (ex.: Zoom) — veja a seção de Reuniões abaixo.

4. Retenção e exclusão de dados

  • Usuários podem solicitar a exclusão da conta via interface. Ao excluir a conta, os dados pessoais são removidos conforme descrito abaixo.
  • Mentor: ao excluir a conta, nome e sobrenome são mantidos apenas como referência para certificação e histórico da aula (ex.: "Aula ministrada por [Nome Sobrenome]"); demais dados do mentor são removidos.
  • Mentorado: ao excluir a conta, seus dados pessoais são excluídos por completo (exceto registros agregados anônimos).
  • Dados relacionados a aulas (título, descrição, presença) são mantidos para histórico e geração de certificados.
  • Retenção para obrigações legais: quando necessário por lei, manteremos dados pelo período exigido.

Solicitações de exclusão, portabilidade ou correção podem ser feitas pelo e-mail de contato (ver seção Contato).

5. Logs e auditoria

O sistema registra logs de eventos técnicos para segurança e operação. Cada registro normalmente inclui:

  • ID do usuário
  • Timestamp (data/hora) do evento
  • Descrição da ação (p.ex. "criou aula", "editou perfil")

Não armazenamos IPs, mensagens privadas ou conteúdos de reuniões. Os logs são utilizados para rastreabilidade e diagnóstico.

6. Reuniões e links (Zoom)

As aulas síncronas podem ser realizadas via Zoom. Importante:

  • Os links de reunião são gerados pela nossa integração com a API do Zoom e enviados automaticamente por e-mail para os participantes cadastrados.
  • Não monitoramos, gravamos nem moderamos as reuniões hospedadas no Zoom. A responsabilidade pela conduta dentro da reunião é dos participantes (mentores e mentorados).
  • Recomendamos que mentores e mentorados não compartilhem publicamente os links ou e-mails de acesso, para preservar a segurança das sessões.
  • Se desejar maior controle (p.ex. exigir senha, sala de espera), essas opções podem ser habilitadas pela configuração da reunião — o administrador/mentor pode escolher opções que exigem senha/registro.

7. Direitos dos titulares

Você tem direitos sobre seus dados pessoais, incluindo:

  • Acesso e obtenção de cópia dos seus dados.
  • Correção de dados incompletos, inexatos ou desatualizados.
  • Exclusão/eliminação dos dados (direito ao esquecimento), observadas as retenções legais e a exceção para manter nome/sobrenome para histórico/certificados quando aplicável.
  • Portabilidade dos dados em formato estruturado e legível.
  • Revogação de consentimento quando aplicável.

Para exercer seus direitos, entre em contato pelo e-mail: orientamais.app@gmail.com.br.

8. Contato

Se tiver dúvidas sobre esta política ou quiser solicitar exclusão/portabilidade, contate: orientamais.app@gmail.com.br.

Termos de Uso

Estes Termos de Uso regem o uso da plataforma OrientaMais. Ao utilizar a plataforma, você concorda com estes termos e com a Política de Privacidade.

Termos — detalhes importantes

1. Objetivo da plataforma

OrientaMais é uma plataforma web que conecta mentores (pessoas que oferecem aulas) a mentorados (pessoas que desejam aprender). Os mentores criam aulas com título, descrição, horário e links de apoio; os mentorados podem se cadastrar e participar das aulas.

2. Idade mínima

Para se cadastrar como mentor, é necessário ter no mínimo 18 anos. Para se cadastrar como mentorado, é necessário ter no mínimo 16 anos. O usuário garante que a informação de idade que fornece é verdadeira.

3. Responsabilidades sobre conteúdo e conduta

  • A OrientaMais fornece apenas a infraestrutura para conectar usuários. Não assumimos responsabilidade pelo conteúdo das aulas, pelo comportamento dos participantes dentro das reuniões, nem por problemas técnicos do Zoom.
  • Mentores e mentorados devem agir com bom senso e não compartilhar links de reunião ou e-mails de acesso de forma pública.
  • Qualquer denúncia de conduta inadequada deve ser reportada ao suporte no e-mail de contato. A plataforma pode, a seu critério, suspender usuários em caso de violação dos termos.

4. Cancelamento e certificados

  • Mentores podem cancelar ou encerrar aulas; o código de presença e a confirmação de presença são controlados pela plataforma.
  • Após validação da presença, a plataforma emite certificados que utilizam nome e sobrenome do mentor e mentorado quando necessário. Mesmo que o mentor exclua a conta, o nome e sobrenome podem ser mantidos para fins de histórico e emissão de certificados.

5. Contas e exclusão

  • O usuário pode excluir sua conta a qualquer momento. Ao excluir:
  • Mentores: serão removidos seus dados pessoais, exceto nome e sobrenome que podem ser mantidos vinculados às aulas para histórico e certificados.
  • Mentorados: todos os dados pessoais são excluídos, salvo logs técnicos agregados ou dados exigidos por lei.

6. Modificações nos termos

Podemos alterar estes Termos de Uso para refletir mudanças legais ou melhorias da plataforma. Alterações serão publicadas com data de atualização; caso relevantes, as alterações serão notificadas aos usuários por e-mail.

7. Legislação aplicável

Estes termos são regidos pela legislação brasileira aplicável.
